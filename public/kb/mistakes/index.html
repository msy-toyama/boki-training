日商簿記3級で不合格になる「よくある間違い＆ひっかけミス」15選と防止対策

更新日: 2026年7月26日

日商簿記3級の試験が終わった後、自己採点で「あれ…？思ったより全然点数が惹かれていない…」とがっくり肩を落とす受験生が後を絶ちません。
実は、簿記検定の作問のプロは、受験者が勘違いしやすい「特定のキーワード・条件」を絶妙に仕込んできます。この「あらかじめ設置されたひっかけのパターン（罠）」を事前に頭にインストールしておけば、失点トラップを簡単に回避し、確実に余裕合格ライン（70点以上）を達成できます！

罠①：小切手の「誰が振り出したか？」問題

小切手に関する取引は最頻出のひっかけポイントです。「小切手を受け取った＝当座預金」と覚えてしまうと即座に失点します。

■ パターンA：他店（他人）振出し小切手の受取

取引先が振り出した小切手を受け取った場合、いつでも銀行の窓口で現金化できるため、簿記上は「当座預金」ではなく「現金（資産）」として処理します。

■ パターンB：自己（当店）振出し小切手の返還

かつて自社が他社に支払い、あらかじめ「当座預金」を減らしていた小切手が、取引の中止などで自社に戻ってきた場合、当座預金口座からのお金の引き落としが発生しなくなった状態なので、「当座預金（資産の増加）」で戻します。

罠②：給料支払時「社会保険料」と「所得税」

従業員に給料を支払うとき、会社は税金や保険料を「天引き」して代わりに役所に納めます。この天引きしたお金を記入する際に、使うべき専門の仮の保管用科目を混同しないようにしましょう。

  • 源泉所得税を取り除いた分：所得税預り金（負債）
  • 社会保険料（健康・年金等）を天引きした分：社会保険料預り金（負債）
  • 会社持ちの社会保険料を計上する時：法定福利費（費用）

※「預り金」と1つの科目でまとめて処理する問題もありますが、別々の科目の指定がないか問題用紙の「勘定科目の選択肢一覧」を必ず先に目視確認する姿勢がミス防止の特効薬です。

罠③：当座預金の残高不足「当座借越」

当座預金残高を超えて小切手を振り出した際、銀行が肩代わりしてくれる「当座借越約定」を結んでいる状況です。 記帳手続きに「一勘定制（当座勘定）」と「二勘定制（当座預金と当座借越に分ける方法）」があり、それぞれで仕訳が異なります。

■ 二勘定制での決算処理

期末に当座預金がマイナスの状態にある場合、その借り越した金額（借金分）は「当座借越」という負債科目に振り替える必要があります。

当座預金✕✕当座借越✕✕

罠④：内金・手付金「前払金」と「前受金」の向き

商品の受け渡し前に授受する内金・手付金は、自分が「払う側」か「受け取る側」かで科目が真逆になります。方向を取り違えると資産と負債を丸ごと間違えます。

■ 自社が支払った内金

後で商品を受け取る権利（資産）が発生 → 前払金（資産）。「仮払金」と混同しない。

■ 自社が受け取った内金

後で商品を引き渡す義務（負債）が発生 → 前受金（負債）。売上はまだ計上しない。

罠⑤：「代金は掛けとした」の一文の見落とし

問題文の末尾に小さく添えられた「代金は掛けとした」「残額は月末払い」といった条件を読み飛ばすと、現金勘定で処理してしまい貸方が総崩れになります。

・商品を仕入れて掛け → 買掛金（負債）／商品以外（備品等）を掛けで購入 → 未払金（負債）

・商品を売って掛け → 売掛金（資産）／商品以外を売って未回収 → 未収入金（資産）

※「商品売買=買掛金/売掛金」「それ以外=未払金/未収入金」の区別が最大の罠。

罠⑥：減価償却費の「月割計算」

期中に取得した固定資産は、1年分まるまるではなく取得日から決算日までの月数で按分します。「1年分で計算して失点」は超頻出です。

例：取得原価 240,000円・耐用年数8年・残存ゼロ・定額法。11月1日取得、決算3月31日（当期は5か月）。

年間：240,000 ÷ 8 = 30,000円
当期：30,000 × 5/12 = 12,500円

罠⑦：貸倒引当金は「差額補充法」で純増分だけ

設定額をそのまま費用計上すると二重計上になります。3級では原則差額補充法を用い、「設定すべき金額 − 現在の残高」の差額のみを繰り入れます。

売掛金 500,000 × 2% = 10,000（設定額）
引当金の残高 3,000 → 繰入額 = 10,000 − 3,000 = 7,000円

貸倒引当金繰入7,000貸倒引当金7,000

罠⑧：消費税（税抜方式）の「仮払」と「仮受」

税抜方式では、仕入時に払った消費税は仮払消費税（資産）、売上時に預かった消費税は仮受消費税（負債）。決算で相殺し差額を未払計上します。本体価格に含めてしまうミスに注意。

決算：仮受消費税 40,000 − 仮払消費税 25,000 = 未払 15,000

仮受消費税40,000仮払消費税25,000
未払消費税15,000

罠⑨：訂正仕訳は「逆仕訳＋正しい仕訳」

誤った仕訳を直すには、まず誤仕訳を反対仕訳で取り消し、続けて正しい仕訳を行います。いきなり差額だけを書こうとすると勘定がずれます（慣れれば相殺形にまとめてOK）。

誤：(借) 現金 / (貸) 売掛金 を、本来 (借) 現金 / (貸) 受取手数料 とすべきだった場合

① 取消：(借) 売掛金 / (貸) 現金
② 正解：(借) 現金 / (貸) 受取手数料
→ 相殺：(借) 売掛金 / (貸) 受取手数料

罠⑩：受取商品券は「現金」ではなく「資産の債権」

自治体や他社が発行した商品券を売上代金として受け取った場合、後で発行元へ請求して換金する債権のため 受取商品券（資産） で処理します。現金で受け取ったと勘違いしないこと。

受取商品券✕✕売上✕✕

罠⑪：手形の「裏書譲渡」と「割引」

受け取った約束手形を他社へ渡す（裏書）・銀行で現金化する（割引）と、受取手形（資産）が減少します。割引時の割引料は 手形売却損（費用） で計上します。

割引例：手形 100,000 を割引、割引料 2,000、手取 98,000

当座預金98,000受取手形100,000
手形売却損2,000

罠⑫：現金過不足は決算で「雑益／雑損」へ

期中に計上した現金過不足のうち、決算日まで原因が判明しなかった残高は、不足なら雑損（費用）、超過なら雑益（収益）に振り替えて精算します。過不足のまま残さないのがルール。

借方に現金過不足（不足）残高 800 が残った場合

雑損800現金過不足800

罠⑬：切手・収入印紙の未使用分は「貯蔵品」へ

郵便切手（通信費）や収入印紙（租税公課）を購入時に費用処理していても、期末に未使用分が残っていれば「貯蔵品（資産）」に振り替え、費用を減額します。翌期首に再振替します。

未使用の切手 1,200 が残った場合

貯蔵品1,200通信費1,200

罠⑭：経過勘定（前払・前受・未払・未収）と再振替

決算で費用・収益を当期分に調整する経過勘定は、方向を間違えやすい代表格です。翌期首の再振替仕訳（決算整理の反対仕訳）まで問われることがあります。

  • 前払費用（資産）：来期分の費用を先払い → 費用を減らす
  • 前受収益（負債）：来期分の収益を先に受取 → 収益を減らす
  • 未払費用（負債）：当期の費用が未払 → 費用を足す
  • 未収収益（資産）：当期の収益が未収 → 収益を足す

罠⑮：法人税等の「中間納付」と「決算確定」

期中の中間納付は 仮払法人税等（資産） で処理します。決算で税額が確定したら、仮払分を差し引いた残額を 未払法人税等（負債） として計上します。中間分の相殺忘れに注意。

確定税額 50,000、中間納付（仮払）20,000

法人税等50,000仮払法人税等20,000
未払法人税等30,000
