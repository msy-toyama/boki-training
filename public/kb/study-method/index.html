勉強法・学習のコツ

簿記の勉強法｜3級・2級を効率よく合格する暗記のコツ・復習サイクル・電卓術

更新日: 2026年8月5日

簿記は「才能」ではなく「正しいやり方での反復」で合格できる資格です。 しかし、やみくもに参考書を読むだけでは、時間をかけた割に得点が伸びません。 この記事では、独学でつまずかないための具体的な勉強テクニック——勘定科目の暗記のコツ、仕訳を反射的に解くトレーニング、間違いを確実に減らす復習サイクル、そして意外と差がつく電卓術——を紹介します。
1ヶ月の学習スケジュールの立て方は 独学一発合格ロードマップ を、専門用語の意味は 簿記用語集 を参照してください。

1. 暗記のコツ：科目を「グループ」でとらえる

初学者がまず挫折するのが、大量の勘定科目の暗記です。ここでのコツは、一つひとつをバラバラに覚えないこと。 すべての科目は資産・負債・純資産・収益・費用の5つのグループに属し、グループごとに「増えたら借方か貸方か」が決まっています。 つまり、覚えるべきは5つのルールだけ。あとは「この科目はどのグループ？」と考えれば、増減の向きは自動的に決まります。

  • 資産（現金・売掛金など）→ 増えたら借方
  • 費用（仕入・給料など）→ 増えたら借方
  • 負債・純資産・収益 → 増えたら貸方

全科目のグループ分けは 勘定科目一覧と5大グループ にまとめています。

2. 仕訳は「読んだら手が動く」まで反復する

簿記の得点力は、テキストを「読む」時間ではなく、仕訳を「解く」量に比例します。 目標は、取引文を読んだ瞬間に借方・貸方が思い浮かぶ状態。ここまで来れば第1問はほぼ確実に得点できます。

そのためには、同じ論点を短い間隔で何度も繰り返すのが効果的です。1問ずつ「なぜその科目なのか」を口に出しながら解くと、記憶への定着が一段と高まります。 スキマ時間にスマホで数問ずつ解くだけでも、積み重なれば大きな差になります。

3. 「間違いノート」で弱点を一点集中でつぶす

合格者の多くが実践しているのが「間違いノート」です。間違えた問題だけを記録し、後日その論点だけを集中的に解き直します。 人は同じところで何度もつまずくため、自分専用の弱点リストを作って重点的に復習するのが、最も効率のよい得点アップ法です。

復習サイクルの例

  1. 問題を解く → 間違えた論点をメモ
  2. 翌日、間違えた論点だけを解き直す
  3. 1週間後にもう一度解いて定着を確認
  4. 本番前に「間違いノート」を総ざらい

受験生がつまずきやすい論点は よくある間違い＆ひっかけ対策 にまとめています。

4. 意外と差がつく「電卓術」

簿記の試験は時間との戦いでもあります。電卓を速く正確に打てるかどうかは、合否に直結します。

  • ホームポジションを固定：数字キーに指を置く位置を毎回同じにすると、見ずに打てるようになります。
  • メモリー機能（M+/MR）を活用：合計計算を途中でメモせず一気に処理でき、転記ミスが減ります。
  • 桁区切りを意識：金額の入力ミスは大きな失点に直結。千円単位を指差し確認する習慣を。

※試験で使える電卓には種類の制限があります。詳細は 試験ガイド と公式の受験案内で確認してください。

5. 総合問題で「時間配分」に慣れる

仕訳が固まったら、決算整理から精算表・財務諸表までの総合問題に取り組みます。 本番形式で解くときは、必ず時間を計って解きましょう。難しい問題に時間をかけすぎず、解ける問題から確実に得点する「時間配分の感覚」が、合格を大きく左右します。
